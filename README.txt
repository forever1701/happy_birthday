# Birthday Website Clone

This is a standalone recreation of the interactive birthday website shown in the supplied reference video.

## Files
- index.html
- css/style.css
- js/script.js
- assets/images/

## Add your own photos
Place these files in `assets/images/`:
- `birthday-photo.jpg` — the photo shown before the final screen
- `final-portrait.jpg` — the full-screen final portrait

You can add additional images and modify the HTML if you want a photo collage.

## Optional music
Place an MP3 at:
`assets/birthday-music.mp3`

The music button in the top-right controls it.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

Bootstrap 5.3.3 and Google Fonts are loaded through CDN.
